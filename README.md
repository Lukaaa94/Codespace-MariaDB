# Codespace-MariaDB

Para un estudiante de ingeniería informática, la recomendación es usar MariaDB.

No solo porque la experiencia de aprendizaje es la misma que con MySQL, sino porque el uso de MariaDB promueve los valores de software libre y la independencia tecnológica, que son pilares fundamentales de la ingeniería de software moderna. Les enseña la importancia de la comunidad, la transparencia en el desarrollo y la sostenibilidad de los proyectos de código abierto.
